# FENS 2026 Interactive Poster

GitHub Pages website for **From Sound to Shape: Reconstructing Vocal Dynamics with Time-Delay Embedding** by Navyanth Kusampudi.

The website keeps the original poster content and visuals, with interactive media only from the supplied dataset.

## Publish with GitHub Pages
1. Upload everything in this folder to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose **main** and **/(root)**, then save.
5. Use the published GitHub Pages URL for the QR code.
